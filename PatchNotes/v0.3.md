## 0.3.1 - Various Bugfixes
- Date: 2026-07-13
- Type: Patch
- Authors: Matathias

Numerous bugfixes and minor changes.

### Changes
- Bugfix: if a settlement has 0 assigned workers, a Consumer Goods calculation could end up dividing by zero
- Bugfix: consumer goods would be re-consumed on game load to re-mitigate events that had already been mitigated
- Bugfix: the event Crop Blight had incorrect penalty multipliers
- Bugfix: if a rural settlement is within tools range of two cities, both cities would be billed for tools even though the rural only benefits from one
- Update a couple of translation keys for the new daily cadence
- Bugfix: the stat modifiers from tools and seasonal production wouldn't immediately re-apply on game load
